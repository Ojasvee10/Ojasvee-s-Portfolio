# 🚀 Getting Started

## Clone the repository

```bash
git clone https://github.com/Ojasvee10/Ojasvee-s-Portfolio.git
```

## Navigate to the project

```bash
cd Ojasvee-s-Portfolio
```

## Install dependencies

```bash
npm install
```

## Run locally

```bash
npm run dev
```

---

# 📦 Build for Production

```bash
npm run build
```
